bookmark 기능을 추가하고자 함.

# Settings dialog에 bookmark 추가
settings dialog의 General tab 우측에 Bookmark tab을 추가.
다음과 같은 layout을 가져야 함:
```
Bookmark
{포트포워딩 상태와 무관하게 menubar에서 서비스에 빠르게 접근하기 위한 기능임을 설명하는 description}

+-------------+---------+-----------+---------+-----------+
|     Name    | Context | Namespace | Service | Port Name |
+-------------+---------+-----------+---------+-----------+
| web sercice |  prod   |  server   | service |    web    |
|  database   |  prod   |  server   | service |           |
|             |         |           |         |           |
|             |         |           |         |           |
|             |         |           |         |           |
+-------------+---------+-----------+---------+-----------+
[+|-]
```

첨부된 사진의 Finder 설정 dialog의 "태그" tab에서 볼 수 있는 strip list ui를 사용.
head column은 strip 항목이 아님
각 항목은 선택 가능해야 함
각 항목은 drag & drop으로 순서를 변경 할 수 있어야하고, 이 순서는 다시 창을 열었을때도 유지되어야 함
item row는 8칸을 유지하고, 8개를 넘는 경우 이 영역 내에서 vertical scroll을 지원해야 함. head column은 scroll 될 때에도 해당 위치에 고정되어있어야 함
`+` 버튼을 누르면 새로운 창으로 dialog가 뜨고 이 때 layout은 다음과 같음:
```
Add Bookmark Item

Name (optional)      [                   ]
Context              [                   ]
Namespace            [                   ]
Service              [                   ]
Port Name (optional) [                   ]

[Cancel] [Add item]
```
- `(optional)`은 secondary style
- Name은 text input. 사용자가 자유롭게 입력 할 수 있음
- Context, Namespace, Service, Port Name은 Select box
    - 현재 kubeconfig 기반으로 선택 가능한 옵션을 제공해야 함
    - Context가 선택되지 않았다면 Namespace, Service, Port Name의 선택이 disabled
    - Namespace가 선택되지 않았다면 Service, Port Name의 선택이 disabled
    - Service가 선택되지 않았다면 Port Name의 선택이 disabled
- Port Name select는 service가 선택되었을 때 확인해서 port item이 한 개가 아니면서 name이 `http`인 item이 존재하지 않는다면 Port Name을 반드시 입력해야 함. 이 조건을 만족하지 못하면 Add item 버튼을 클릭했을 때 service의 port item이 여러개라서 서비스를 지정할 수 없다는 에러 메시지를 표시하고 bookbark item 추가 없이 add bookmark item dialog를 유지해야 함
- select box는 select item이 열린 상태에서 키보드로 검색 할 수 있어야 함. 해당 문자열을 포함하는 경우만 필터링해서 목록을 보여줘야 함
- [Add item] 버튼을 클릭하면 Bookmark 가장 아래에 이 값으로 항목을 추가하고 add bookmark item dialog를 종료
- 같은 `(Context, Namespace, Service, Port Name)`이 이미 있으면 [Add item]을 눌러도 항목, 순서, 입력과 창을 그대로 유지한다. 기존 항목의 `Name`도 바꾸지 않는다. 서로 다른 대상은 같은 `Name`으로 저장할 수 있다.

# Menubar에 bookmark 추가
Recent Services menu 바로 위에 (구분선 없이) Bookmarked Services 메뉴를 추가.
hover하는 경우 highlight 되어야하고 우측 또는 좌측으로 popover가 열려야 함. (recent services 처럼)
이 popover의 최상단에는 `[Search...       ]` 형태의 text input이 있고, name, context, namespace, service, port name 중 일치하는 항목이 있는 bookmark item만 필터링해야함
검색창 아래에는 구분선을 두고 그 아래에 bookmark에서 지정한 순서대로 항목을 보여줘야하고, 포맷은 다음과 같음: `{name} ({service}.{namespace}.{ctx})` 만약 port name이 지정된 경우에는 `{name} ({portName}.{service}.{namespace}.{ctx})` 형태로 표시. 어느쪽이든 괄호를 포함해서 괄호 내용은 secondary style
이 항목은 hover 되었을 때 highlight 되어야하고 클릭하면 `http://{portName}.{service}.{namespace}.{ctx}.{domain}:{port}` 또는 `http://{service}.{namespace}.{ctx}.{domain}:{port}` 형태의 주소를 클립보드로 복사하고 `Copied`를 1초간 표시 (Recent services 참고)
예를 들어 `http://serviceName.namespace.context.kuri.localhost`가 복사되어야 함 (port=80일때는 생략)
